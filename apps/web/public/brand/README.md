# FORM Coach Desk brand assets

These are the approved source images supplied by the Product Owner. They must be used directly;
do not recreate their geometry, replace their lettering, or generate substitute logo variations.

| Asset                          | Intended use                                                    |
| ------------------------------ | --------------------------------------------------------------- |
| `form-icon.png`                | Light icon artwork for dark surfaces, favicons, and compact use |
| `form-horizontal.png`          | Light horizontal lockup for dark surfaces                       |
| `form-icon-on-light.png`       | Dark icon artwork for light surfaces and compact use            |
| `form-horizontal-on-light.png` | Dark horizontal lockup for light surfaces                       |
| `form-pwa-icon.png`            | Dark tile with neon artwork for PWA and browser icons           |
| `form-apple-touch-icon.png`    | Opaque full-bleed dark iOS icon; iOS applies the corner mask    |
| `launch-390x844.png`           | Dark iOS launch image for 390 x 844 point, 3x devices           |

Choose the variant for the surface it sits on. Do not recolour the logo or change the surrounding
surface merely to accommodate one variant: use the `*-on-light.png` artwork on light backgrounds
and the original light artwork on dark backgrounds. Keep the supplied transparent canvas intact.
The original PWA/browser icon remains unchanged. The Apple touch icon is a derived full-bleed
version without the original tile's transparent outer canvas and premasked corners, so iOS applies
only its own rounded mask. The launch image uses the approved horizontal mark on the dark surface.
