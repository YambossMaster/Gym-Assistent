## Boundary and contract

- On a Session's Training Record, show the immediately preceding and following non-cancelled, dated Session for the same Session owner (person or group), ordered by start time and ID. A future scheduled Session is a valid next lesson. Hide either direction when absent. No cross-owner or legacy lesson navigation.
- Desktop: full-width previous/next controls labelled `前次課堂` and `下次課堂` flank the more prominent student identity. Each retains local date/time and a subdued directional arrow. Mobile: small arrow controls with full accessible names flank the avatar and name; existing lesson actions remain on the same line. At 380px and below, action labels collapse to icons to retain clearance. Keep Training Record and Coach Note tabs, save state and bottom controls intact.
- Return adjacent Sessions with the verified Coach's Session detail projection. The Scheduling Module reads the current Session and same-owner schedule within its Workspace boundary. No new endpoint, table, public capability or migration.
- Before switching, flush a pending training autosave; stay on the current Session if synchronization fails, is offline or the local draft store reports an error.
