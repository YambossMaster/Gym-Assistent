## 一筆明細的來源與狀態

系統產生的每筆明細有穩定來源識別，例如學生購課、場地預購、單堂租金、
抽成或差額，以及「場地 × 月份」的底薪。月報從來源計算一筆原始明細，
再套用**僅作用於這筆明細**的人工調整。場地課程紀錄和場地／學生設定仍是
原始資料；修改、隱藏或恢復收支明細都不回寫這些來源。

| 狀態     | 在收支明細的行為                                                    | 對月份總額的影響   |
| -------- | ------------------------------------------------------------------- | ------------------ |
| 系統原始 | 顯示來源計算值與來源連結。                                          | 計入。             |
| 已修改   | 顯示手動欄位及 **已修改**；標記可開啟 **取消修改**。                | 以手動值計入一次。 |
| 已刪除   | 不列在正常明細；收進可展開的 **已刪除明細**，可 **恢復**。          | 不計入。           |
| 自行新增 | 獨立建立一筆收入或支出，標記 **自行新增**；不偽裝成課堂或購課來源。 | 計入。             |

一筆系統明細可以先修改、再移到已刪除。恢復後保留刪除前的人工版本
及 **已修改** 標記；若來源在此期間變動，再標示 **來源已變動** 並提供
重新計算值供檢視。使用者自行新增的明細若再刪除，視為從未新增，
不留在已刪除明細中；新增明細可直接編輯自己的欄位，但仍維持
**自行新增**標記，不另外冒充系統 **已修改** 明細。

刪除系統明細是「在收支明細中隱藏」，不是刪除 Course Session、學生購課、
場地預購或底薪規則。恢復後再按來源與尚存的人工修改顯示。若來源資料
在明細隱藏期間改變，仍保留隱藏狀態，顯示來源已變動資訊；使用者恢復時
應先看到目前來源與恢復後金額。若來源本身被永久刪除，不能悄悄把它
當成仍存在的系統事實；已刪除列表保留最後快照和 **來源已移除**，
恢復入口改成明確的 **另存為自行新增**，建立一筆無來源的手動明細。

## 修改、新增與取消修改

每筆系統明細只允許調整該筆可編輯欄位，不能改到同一來源的其他月份。
例如某月薪水實收不同，修改該月的底薪明細只影響該月；**前往場地底薪設定**
才會改底薪規則並影響後續應用的月份。逐堂租金、抽成、學生購課與預購
也提供對應的 **前往來源設定／紀錄**，避免把財務數字修正誤當成原始資料修正。
Product Owner 已確認系統明細可單獨修改**金額、日期與時間、名稱**，收入／支出
方向鎖定。若要改方向，先將原系統明細移到已刪除，再自行新增正確方向
的明細；原系統明細仍可恢復，不自動消除新明細。修改日期時間使明細移至
另一月份時，來源原始日期仍保留供查看，新舊月份總額同步更新。

**取消修改**移除該筆人工欄位覆寫，回到來源**最新**的計算值；若來源在
修改後曾變動，取消前要顯示即將恢復的值。使用者已確認來源改變不會
默默覆蓋手動修改，而會保留手動值並標示 **來源已變動**。

自行新增明細至少需要日期、時間、名稱、收入或支出、金額及幣別，可附註說明；
沒有 Session、Venue、Student 或薪資規則來源。它可獨立編輯，刪除即移除。
所有金額用整數最小貨幣單位及 ISO 幣別；不同幣別不合併總額。

## 頁面與計算

**本月收支**及**各月收支紀錄**使用同一套明細狀態。正常明細列出系統原始、
已修改及自行新增；**已刪除明細**單獨折疊顯示被隱藏的系統列，
並可按月份查看，避免長列表遮住主要收支。列表列與標記都可用鍵盤及
觸控開啟操作；桌面與精確 390×844 都能完成編輯、新增、隱藏、恢復、
取消修改與來源跳轉。恢復／取消修改前若來源已變動，要預覽新的金額。
兩個列表均依每筆明細**顯示的日期與時間**排序，同一時刻再用穩定明細 ID；
建立時間、修改時間及刪除時間不參與排序。手動修改日期時間後，立即依新
位置排序及歸屬月份。原始來源若只有日期、沒有真實時間（例如按月發薪日
或舊的場地預購日期），按該 Workspace 當日最早位置排序，但畫面只顯示
日期，不把排序用的 00:00 冒充為真實付款時間；一旦教練手動填入時間，
則改依該時間排序。

當月與歷史月總額只匯總正常明細的**實際顯示金額**：人工修改取手動值，
自行新增計入，已刪除排除。購課／底薪收入與場地支出仍分幣別呈現；
手動新增的收入或支出歸入相同方向的月總額。來源計算值與顯示值都保留，
方便辨認差異，不讓手動修改反向改掉場地課程紀錄。
Product Owner 已確認頁首數字採**調整後收入**，有人工修改、新增或刪除
影響該月時標註 **含手動調整**。因調整後收入可能包含底薪或自行新增收入，
頁首不能仍稱 **本月學生購課總額**；應使用 **本月已記錄收入**，並在明細中
保留每筆購課來源與原始計算值。場地支出及試算差額同樣採調整後有效明細。

## 持久資料、操作與狀態

系統明細以來源種類及來源 ID／月份組成穩定識別；底薪以場地和應付月份識別。
人工覆寫及隱藏狀態是獨立的 Workspace-scoped 私有紀錄，保存來源版本、
手動欄位及操作版本。自行新增明細有獨立 ID、完整日期時間、名稱、方向、
金額、幣別及選填備註。正常列表用原始來源加人工覆寫投影；已刪除列表
用來源快照及隱藏狀態投影。來源變動時不消除已修改或已刪除狀態。

| 操作         | HTTP                                              | 必要輸入及效果                                                         |
| ------------ | ------------------------------------------------- | ---------------------------------------------------------------------- |
| 讀取月份     | 既有 `GET /v1/finances/current`、`/months/:month` | 回傳有效明細、調整後總額、來源值／顯示值、標記及已刪除筆數。           |
| 已刪除明細   | `GET /v1/finances/deleted?month=YYYY-MM&cursor=…` | 依單筆顯示日期時間分頁，不包含已刪除的自行新增明細。                   |
| 自行新增     | `POST /v1/finances/entries`                       | 日期時間、名稱、方向、金額、幣別、選填備註；只產生手動來源。           |
| 編輯單筆     | `PATCH /v1/finances/entries/:entryId`             | 來源與操作版本；只接受金額、日期時間、名稱，方向及幣別鎖定。           |
| 刪除單筆     | `DELETE /v1/finances/entries/:entryId`            | 系統明細變為已刪除；自行新增明細直接移除，不留已刪除紀錄。             |
| 恢復系統明細 | `POST /v1/finances/entries/:entryId/restore`      | 移除隱藏狀態，保留刪除前的手動修改；來源消失時改走明確另存為自行新增。 |
| 取消修改     | `DELETE /v1/finances/entries/:entryId/adjustment` | 只移除該列欄位覆寫，顯示來源最新計算值。                               |

每個操作都由驗證身分解析 Workspace，檢查該 Workspace 的來源、修改版本及
明細狀態，不接受前端提供 Workspace ID。改名／改日期時間不會改源資料；
編輯收入／支出方向的要求應回應「請刪除原明細並自行新增」。各月查詢及
Today 若顯示財務摘要，都必須使用同一套調整後投影。初讀取、空清單、
局部錯誤、背景更新、操作中、版本衝突、來源變動與來源已移除都有可恢復狀態。

## 已確認規則與驗收

1. Product Owner 已確認系統明細可改金額、日期與時間、名稱；方向鎖定，
   需改方向時刪除原明細再自行新增。
2. 修改後刪除的系統明細恢復時保留刪除前的手動版本；取消修改另行恢復
   來源最新計算值。
3. 來源永久刪除後，已刪除明細只能經明確 **另存為自行新增** 恢復其數字，
   不偽裝成仍有來源的系統明細。
4. Product Owner 已確認頁首顯示調整後收入並標註含手動調整；因範圍不限
   於學生購課，標題改為 **本月已記錄收入**。
5. Product Owner 已確認所有明細按單筆顯示日期與時間排序，而非建檔或
   修改時間。
6. Stage 1 桌面驗收補充：收支明細內層清單在頂端繼續向上捲動時，讓外層頁面接手；
   管理明細標題與表單以細線及間距分開。系統明細的來源資料使用有標題的
   **來源說明** 欄位，操作列沿用表單按鈕規格與 Ctrl/Cmd + Enter 儲存。
7. 場地課堂支出明細的來源連結直達該場地的 **場地課程紀錄**，捲至相符課堂並
   以淺綠色標示。關閉該介面、使用場地頁返回入口或瀏覽器上一頁時，恢復原
   收支月份及管理明細；若紀錄已不可用，保留返回入口並明示找不到該筆。

驗收需涵蓋：單月薪水改額不改規則、相同來源的其他月份不變、原始列
修改→取消修改、修改→刪除→恢復、來源變動期間維持修改或隱藏、
手動新增→刪除不留已刪除紀錄、歷史月份恢復後總額更新、幣別分組、
跨 Workspace 不可讀改、版本衝突與重複提交只作用一次。
