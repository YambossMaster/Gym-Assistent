# 日曆整合 — 產品規格草案

> 2026-10-10 · Product Owner 已核准產品規格並授權開始實作。
> 工程補充見 `SETTINGS-DATA-IMPLEMENTATION.md`。資料庫遷移僅先建立檔案；
> Production 套用、完整驗證與 remote delivery 仍依各自授權門檻。

## 1. 定位與入口

讓教練在慣用日曆看到 Form Coach Desk 的課程安排，避免維護兩份行程。
提供「日曆訂閱」為主要功能，「下載 ICS」為一次性搬移的次要功能。
只做 Form Coach Desk → 外部日曆的單向讀取；排課、改期與取消仍在本產品進行。
不提供 OAuth 雙向同步、Google 帳號連接、學員邀請或出席回覆。

設定入口沿用 [收支明細規格第 3 節](FINANCE-EXPORT-DRAFT.md#3-設定資訊架構與方案行為)：
「設定 → 資料與裝置 → 日曆整合 → 設定日曆」。與收支是獨立區塊與專屬介面。
Free／Pro 點擊仍開啟既有 Prime Upsell；保留查看方案與關閉，不新增日常工作路徑入口／Banner。
Prime 直接進入日曆設定。所有有效 Prime 來源都適用，不只付費訂閱。

## 2. 日曆內容

首次啟用前可預覽一筆「範例」卡片，反映即將分享的欄位，不讀取多餘學員資料。

| 設定         | 建議預設 | 說明                                                        |
| ------------ | -------- | ----------------------------------------------------------- |
| 課程         | 包含     | 已實際建立且有日期時間的課堂                                |
| 顯示學員姓名 | 關閉     | 關閉時課堂統一顯示「教練課程」；開啟顯示「教練課程 · 姓名」 |
| 顯示地點     | 開啟     | 使用該課堂正式 location；無值時省略                         |

每筆包含開始、結束和地點（若啟用）；名稱選項不額外暴露電話、Email 或學員 ID。
Settings 不提供封鎖／可排課時段的匯出選項；訂閱與一次性下載只輸出課程。
不輸出訓練內容、私人教練筆記、學員介紹、收支、購課堂數、公開分享連結或 Auth token。
完成課堂保留在過去範圍，可在標題標「已完成」。不以 iCalendar 的取消狀態代表完成。
不輸出可預約時段或衝突警告；訂閱不是預約頁。

首次確認文案：「訂閱網址可讀取你選擇的行程資訊，請勿公開分享。更新時間由日曆服務決定。」

## 3. 範圍與排課事實

訂閱採固定滾動範圍：Workspace 今日往前 30 天至往後 180 天，範圍每日前移。
輸出與此區間相交的事件，跨日只出現一次，保留原始起訖時間。
第一版一個 Workspace 一個有效訂閱設定，沒有依學員／場地建立多條連結。

只包含系統已建立的課堂。現有自動排課只支援不自動／一週／兩週，
「未來 180 天」不是保證已有 180 天課程；不可把固定排課規則自行展開成未確認事件。
介面在內容範圍旁寫「僅包含已排定的課程」。訂閱請求不得建立課堂或改變排課。

## 4. 訂閱流程與連結管理

1. Prime 點「設定日曆」，預設進入「日曆訂閱」頁籤，看到狀態、內容設定、即時範例與網址。
2. 按「啟用日曆訂閱」確認分享範圍後產生專屬網址。
3. 提供單列 HTTPS 網址與右側圖示複製按鈕；長網址在欄位中截斷，不另佔一列。將進階管理緊接在網址之後；Google／Apple 教學放在最後的預設收合清單，使用者需要時可自行展開。
4. Google 說明使用電腦瀏覽器，在「其他日曆」旁按＋、選「透過網址」、貼上並新增；
   明示 Google 手機 App 不能直接加入網址，但同帳號會看到電腦端加入的日曆。
5. Apple 同時說明 iPhone／iPad 的「行事曆 → 加入行事曆 → 加入訂閱行事曆」與
   Mac 的「檔案 → 新增日曆訂閱」，提醒貼上完整網址並確認 SSL。
6. 教學結尾說明第一次出現與後續更新可能需要時間，且要持續同步就不能改用一次性 ICS 匯入。
7. 顯示內容的核取方塊在調整後立即保存，不提供手動儲存按鈕，也不向使用者解說內部保存機制；只有失敗需要提供可採取行動的提示。建立、複製與管理結果以不推動版面的短暫 Toast 顯示；不因複製／開啟外部 App 就顯示「已連線」或「同步成功」。

Apple 官方支援以網址加入訂閱；Google 官方的 From URL 流程由電腦瀏覽器操作。
本產品用可撤銷的持有者網址讓外部服務抓取，不是 Google 登入授權，網址必須保密。
實際 Apple 初次訂閱與 Google 私密路徑初次訂閱已用合成事件驗證；外部平台的後續刷新時機
由平台決定，尚未驗證。詳見文末官方來源與安全驗證紀錄。

2026-10-10 PO 後續修正：有效訂閱的網址必須在管理頁持續可取用，不再採關閉後消失的
一次性顯示。API 使用專用 server-only secret 與每個 Workspace 的隨機 salt 決定性推導
256-bit token；私有資料庫只保存 salt 與 token 的 SHA-256，不保存原始 bearer token。
Authenticated GET 可為該 Workspace 的已驗證 owner 重建同一網址。舊版只有 hash、沒有 salt 的
既有連結不會被自動輪替；介面提示重設一次後才可常駐複製。

| 管理動作     | 結果與確認                                                       |
| ------------ | ---------------------------------------------------------------- |
| 修改分享內容 | 使用同一有效連結並自動儲存；下次外部抓取反映；已下載內容無法收回 |
| 重設連結     | 舊連結立即失效、顯示新連結；確認文案說明所有既有訂閱需重新加入   |
| 停用訂閱     | 撤銷連結，後續請求不再取得行程；已下載內容可能仍留在外部日曆     |
| 停用後再啟用 | 產生新 token，舊連結不復活；不自動重新訂閱外部服務               |

重設／停用採版本檢查；重複點擊或網路重試不產生多個有效連結。
建立回應遺失時重新查管理狀態並還原同一網址，不盲目重建。
跨裝置設定衝突保留本次輸入並提供重新載入，不默默覆寫。

## 5. 改期、取消、刪除與方案變動

改期使用同一事件 UID，更新時間及修訂版本，不能每次匯出隨機生成新 UID。
每堂固定課是獨立事件，第一版不輸出 RRULE，避免與實際課堂／例外日期重複。

取消與刪除必須使外部日曆在刷新後不再把舊課堂當作有效行程。
提案保留同 UID 的取消標記，必要時以不含姓名／地點的撤除記錄支援硬刪除；
改期到範圍外、改隱藏姓名及滾動淘汰也須納入客戶端回歸。
取消標記保存 210 天為待驗證上限提案；不得假設只從 feed 移除就能立即清掉所有客戶端快取。
這需要新的持久狀態與遷移評估，並非現有匯出 formatter 的小修改。

每次 feed 抓取都查當前 Prime 與帳號可用狀態。
2026-10-10 PO 增補：Prime 失效／降級後立即停止提供真實事件，改回 HTTP 200 的單一
「Prime 方案已到期」提示事件。提示採固定 UID、失效首次確認日的全天日期、不占忙碌時間、
不含提醒、課程時間、姓名、場地或備註。失效連結只保留讀取此提示的能力；清除已發佈事件紀錄。
重新取得 Prime 後由教練主動建立新連結，避免舊持有者自動恢復讀取。
明確停用／重設仍撤銷舊連結，不存在或撤銷的憑證不取得提示。權限服務錯誤保持失敗關閉，
不冒充方案到期或回傳舊內容。產檔前後均確認權限，不使用 304 繞過當前權限檢查。
提示取代完整 feed，目的在外部日曆成功刷新時取代舊事件；不能保證刷新時間或清除離線／匯入副本。
帳號刪除或不可用立即禁止讀取；清理私人記錄按既有帳號生命週期執行。
非 Prime 仍能看已建立整合的管理狀態並停用／撤銷；此安全操作不能被 Upsell 擋住。
建立、重設、下載及增加分享內容仍需 Prime，點擊時保留 Upsell。

撤銷是阻止後續抓取，不保證刪除 Google／Apple 或其他持有者已複製的資料。
畫面不提供無法控制的「立即同步」按鈕，也不顯示臆測的完成時間或刷新倒數。

## 6. 一次性 ICS 下載

同一設定對話框以「日曆訂閱」與「單次匯出」兩個頁籤分隔長期同步與一次性下載，
不再使用垂直折疊面板，也不建立第二個 Settings 功能欄位。
預設未來 30 天，提供本月、下個月、自訂（最多 366 日），按相交區間選擇事件。
使用相同分享欄位預設，但本次調整不改動持續訂閱設定；按鈕「下載 ICS」。
只含選定範圍內有效的預定／完成課堂，不含封鎖／可排課時段或訂閱撤除用標記。
下載前明示「匯入後不會自動更新；若需要後續改期更新，請使用日曆訂閱」。
無事件可產生有效空訂閱 feed；一次性下載則顯示「此期間沒有行程」，不下載空檔。
同一檔案反覆匯入可能依客戶端產生重複，不承諾 UID 能讓手動匯入自動去重。

## 7. 工程設計邊界（待工程 Contract）

- 管理操作走 authenticated API，從已驗證身分解出 Workspace，Web 不傳租戶 ID。
- feed 是僅供日曆讀取的狹窄能力入口；不使用 Coach JWT，不重用 `/t/:token` 或 `/r/:token`。
- token 由專用 API-only 32+ 字元 secret、Workspace ID 與每次建立／重設產生的 128-bit
  隨機 salt，以 HMAC-SHA-256 推導為 256-bit bearer token。服務端只存 salt 與 token hash；
  secret 不進資料庫、Web bundle 或日誌，且不得與登入密碼或其他營運 secret 共用。
- 使用 `/api/v1/public/calendar/:token.ics` 私密路徑；Authenticated owner 可在訂閱有效時
  重新取得同一網址。原始 token 仍不落庫。
  PO 接受 Fly.io 上游除錯日誌可能記錄請求路徑的剩餘風險；應用日誌仍只記路由模板，
  不記 token、完整網址、Authorization 或 Cookie。feed 不載入追蹤碼，不做外部轉址，
  不暴露 Workspace／Auth ID。
- 使用 HTTPS、no-store/private、noindex/no-referrer；不進 PWA cache、公共 CDN 或共享快取。
  外部日曆仍可能保存內容，這些 headers 不是可遠端撤回資料的保證。
- 不存在／明確撤銷的連結統一無內容錯誤；有效但 Prime 失效的連結只回前述提示。
  不 redirect 到登入 HTML，也不在失效回應中回傳課堂資訊。
- 限速與有界查詢；提案每次最多 10,000 個事件（含取消標記）、10 MiB、30 秒。
  超量／內部錯誤不傳 200 空日曆，避免被誤認為所有行程已刪除；不得靜默截斷。
- 日曆 serialization 採 RFC 5545：穩定 UID、UTC 起訖、可靠的修訂時間／序號、
  UTF-8、CRLF、內容 escaping 與 75 octet 行折疊；禁止不可信文字注入額外屬性／事件。
- 不加入 ATTENDEE、邀請 METHOD 或預設提醒。UTC 儲存與外部日曆本地顯示不改變實際時間。
- Scheduling 提供範圍投影；feed 只拿白名單欄位，不先讀完整私人 Training／Student 物件再刪欄位。
- 課堂與區塊變更、刪除的修訂／取消投影及保留期限，必須在實作前補齊共享介面、遷移與清理契約。

## 8. 狀態與驗收

介面包含載入、尚未啟用、建立中、已啟用、保存中、已停用、方案失效、
空行程、錯誤、版本衝突與 ICS 下載狀態；狀態區預留空間，複製失敗可手動選取。
設定視窗遵循固定標頭／中間捲動／固定操作區；成功與失敗皆可鍵盤、觸控與讀屏操作。

驗收必須包含：

- Free／Pro 主動點擊時仍有 Upsell；日常收支／行事曆沒有新增行銷干擾。
- Prime 建立、設定保存、複製、重設、停用、失效、重新啟用與安全管理例外。
- 單次 ICS 可在 Apple／Google 正確匯入；真實訂閱可抓取且改期不增生重複事件。
- 取消、硬刪除、跨範圍改期、顯示姓名→隱藏、Prime 失效後的實際外部行為。
- 以合成資料和專用外部日曆測試；記錄操作時間、觀察到的刷新時間和平台版本，
  不把一次快速刷新當作日後的 SLA，不因尚未刷新就誤稱產品失敗或成功。
- 中文、長文字、逗號／分號／換行、Unicode 折疊、跨日、DST、重複規則實體課堂。
- 兩個 Coach 的 token 與管理操作隔離，日誌無原始 token，無任何私人筆記流出。
- 空 feed 與錯誤 feed 區別、容量超限、濫用限速、失敗回復及行程服務負載。
- 桌機、390×844、安裝 iOS／Android PWA 的複製／外部跳轉／返回流程分別驗證。
