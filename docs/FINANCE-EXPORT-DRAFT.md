- 保留既有點擊式 Upsell：Free／Pro 主動點擊功能按鈕後，顯示 Prime 說明與「查看方案」。
  不是取消 Upsell，也不是隱藏功能。一般設定列本身不整列變成推銷按鈕。
- 訓練紀錄與個人表現的匯出選項暫時撤下；原有應用內查閱與資料保留。

## 2. 使用者工作與成功標準

教練需要把某期間的收支交給會計，或在 Excel／Google Sheets 分析。
成功標準是：收件者不必改欄名、換算金額、刪除內部 ID 或拆解合計列，就能開始整理。
會計可以追查來源，教練可以核對與應用內相同範圍的收支。

第一版提供記帳與會計整理用資料；不計算稅額、不判斷可扣抵項目、不產生發票、
報稅申報檔或銀行對帳結果，也不把「收支差額」稱為淨利或帳戶餘額。

## 3. 設定資訊架構與方案行為

建議沿用 `/settings?category=data`「資料與裝置」，不增加頂層導覽分類。
將現有「匯出資料」替換成兩個獨立區塊，裝置暫存區塊留在下方。

| 順序 | 欄位                   | 說明                                   | 動作         |
| ---- | ---------------------- | -------------------------------------- | ------------ |
| 1    | 匯出收支明細           | 下載指定期間的收支，供記帳與會計整理。 | 設定匯出     |
| 2    | 日曆整合               | 在慣用的日曆查看課程與行程。           | 設定日曆     |
| 3    | 原有資料保存與裝置暫存 | 沿用原有功能                           | 沿用原有動作 |

分類摘要改為「匯出收支、設定日曆整合與管理裝置暫存」。
兩個功能各自保留既有小型 Prime 權限標記；不新增促銷段落、折扣或自動彈窗。
Prime 點擊後直接進入功能；Free／Pro 點擊後沿用 Upsell，關閉即回原設定位置，
「查看方案」進入既有方案頁。只維持本次兩項功能的入口約束，不全面重做其他方案提示。
方案讀取失敗顯示重試，不誤判為非 Prime；服務端每次產檔都重新檢查有效 Prime。

## 4. 匯出流程

1. 點「設定匯出」，開啟專屬「匯出收支明細」表單，不再選資料類型。
2. 選期間：上個月（預設）、本月、今年、去年、自訂。
3. 選範圍：全部場地（預設，含未指定場地）、單一場地、未指定場地。
4. 選格式：Excel（`.xlsx`，預設）、CSV（`.csv`）。兩者都包含收入與支出，
   不提供容易產生不完整結算的單一方向開關；下載後可自行篩選。
5. 「包含收支私人備註」直接顯示（預設關閉，每次匯出重新選擇），不為單一選項增加折疊操作。
6. 固定底部以次要文字摘要期間、場地、格式及是否含私人備註，視覺焦點保留給
   「下載 Excel／下載 CSV」。

表單依操作順序分成「時間區間」、「資料篩選」與「匯出設定」三段。快速區間、場地與
格式選擇器都顯示持續可見的欄位標籤；預設值不能代替欄位名稱。快速區間與開始／結束
日期留在同一段，讓使用者理解兩者會互相更新。

日期依 Workspace 時區，起訖日都包含；本月／今年截止今日。自訂區間最多 366 日，
可選任意歷史年度，例如完整的 2024 年；不是只能回溯最近 366 天。
不含未來日期。上限是待實測的提案，不沿用舊 31 天限制來阻擋年度用途。
歸檔場地仍可篩選歷史收支。第一版不加欄位拖拉、自由組報表、排程寄送或 ZIP。
不在每次改選項時查全量資料；下載前摘要是選項摘要，不假裝已驗證筆數或金額。

## 5. 資料規則

權威來源是 Finance Module 的當前可見帳本，保留既有更正與隱藏規則。
按帳本的有效日期篩選，按有效日期、時間、穩定來源鍵排序。
已隱藏列不匯出；手動新增列包含在內。沒有場地的列在「全部」或「未指定」時納入。
不能從 label 字串解析學員身分或推測付款方式；使用既有正式欄位。

- 收入、支出進入明細與合計；`reference` 參考列不進入兩者，第一版不另外匯出。
- 不因完成一堂課就再次計入購課收入；不因使用預購場地堂數而再次列支。
- 保留負的支出調整，例如沖減抽成；不取絕對值、不擅自改成收入。
- 不同幣別分開合計，不換匯、不產生跨幣別總額。
- 原始金額沿用正式帳本的整數單位規則，輸出與應用內顯示一致。
  2026-10-10 實作核對修正：既有模型的 TWD 單位為元，123450 輸出為 123450 元；
  USD 123450 分則輸出為 1234.50 美元。不得將 TWD 再除以 100，也不遷移既有金額。
- 原本缺少的值留空；金額零仍是 0，不與缺值混淆。
- 明細是產生當下的帳本內容，不是不可變歷史結帳快照。檔內記錄產生時間與時區。
- 來源已變更但存在帳本更正時保留目前可見金額，並在核對提示中說明，不自行修正。
- 未追蹤費用、缺價格或未能計算的項目不是零成本。摘要需列資料完整性提醒與數量；
  Finance Module 須提供相同期間／場地的缺漏投影，不能僅由匯出列推論完整性。

## 6. Excel 與 CSV 成品

Excel 一個檔案，兩個工作表：

- **收支摘要**：教練顯示名稱、期間、場地、時區、產生時間、各幣別收入／支出／差額，
  以及依月份、分類、場地的各幣別小計；列出資料完整性提醒。
- **收支明細**：一列一筆，凍結標題、啟用篩選、日期與金額有正確儲存型別，
  不合併儲存格、不插入小計或空白分隔列。文字欄可換行。

摘要使用服務端同一份選取結果計算的靜態值；檔案是匯出當下快照，使用者在 Excel
修改明細後摘要不會自動重算。第一版不提供公式連動，以免暗示它是可持續維護的帳簿。

| 明細欄位（順序） | 規則                                                               |
| ---------------- | ------------------------------------------------------------------ |
| 日期             | 有效帳務日期；Excel 日期型別，CSV `YYYY-MM-DD`                     |
| 時間             | 工作時區時間；無紀錄時留空，不補出午夜                             |
| 項目             | 當前可見項目名稱                                                   |
| 分類             | 購課、場地結算、場地預購、場租、抽成、底薪、自行新增等人類可讀名稱 |
| 場地             | 未指定時留空                                                       |
| 收入             | 數值；支出列留空                                                   |
| 支出             | 數值；收入列留空，保留負的支出調整                                 |
| 幣別             | ISO 幣別，例如 TWD                                                 |
| 說明             | 既有帳本明細，不混入私人教練筆記                                   |
| 紀錄狀態         | 原始／已更正／自行新增                                             |
| 核對提示         | 如「來源資料已變更」；正常列留空                                   |
| 來源編號         | 穩定的帳本列鍵，放最後作核對，不當主要閱讀資訊                     |
| 私人備註         | 只在本次勾選時出現；僅手動收支備註，其他列留空                     |
| 時區             | Workspace IANA 時區                                                |
| 匯出時間         | 含 offset 的產生時間，便於 CSV 離開原檔名後追查                    |

CSV 使用相同明細欄位、UTF-8 BOM、一列標題，不附摘要列或文字前言。
金額用無千分位的十進位數字；正確處理逗號、引號、換行及公式注入。
Excel 的外部輸入一律是文字儲存格，不讓使用者文字成為公式或外部連結。
中文檔名：`[呂曉白]_收支明細_2026-01-01_2026-12-31_20270105-1430.xlsx`。
名稱取自教練顯示名稱，清除路徑／控制字元與不安全檔名字元並限制長度；空值回退「教練」。
本例只是命名示意，不是目前的實際匯出結果。

不新增付款方式、發票號碼、稅額、稅別、付款狀態等現有模型沒有的欄位。
這些需求若之後成立，必須從原始記錄流程設計，不能只在匯出檔加空欄充數。

## 7. 狀態、效能與手機

維持固定標頭、單一中間捲動區、固定底部操作；採用現有日期／選項元件。
390×844 不水平溢出，選單展開和鍵盤出現後仍能抵達欄位與下載按鈕。

| 狀態       | 行為                                                 |
| ---------- | ---------------------------------------------------- |
| 載入／錯誤 | 只影響此功能，保留設定頁；可重試                     |
| 空資料     | 顯示「此期間沒有收支紀錄」，不下載空檔；保留條件     |
| 產生中     | 固定狀態區顯示進度文字；禁止重複提交，不顯示假百分比 |
| 關閉表單   | 取消本次請求，沒有暗中繼續下載；重新開啟可再操作     |
| 成功       | 顯示「檔案已開始下載」與檔名，不宣稱已存入手機       |
| 網路失敗   | 保留條件，提供重試；清除舊成功訊息                   |
| 超量／超時 | 不回傳部分檔案，說明改選月份或場地；不靜默截斷       |
| 權限失效   | 不交付檔案，清除舊下載狀態，沿用點擊式 Prime 說明    |

建議第一版採單次請求，不新增背景工作、歷史檔案或通知系統。
暫定最多 20,000 列、10 MiB、30 秒，必須以年度資料在實際 host 路徑做負載驗證。
若正常年度用途不能達標，先調整查詢／產檔或回到 Contract 決定背景機制，不能宣稱已支援年度匯出。
查詢、計算與寫檔都要有界限；事後只限制檔案大小不算完成。

## 8. 技術邊界與驗收

提案使用獨立 authenticated Finance Export operation，Web 不傳 Workspace ID。
Finance Module 提供同一快照的明細、分類與缺漏，輸出 adapter 負責檔案型別。
下載不保存於資料庫／檔案庫，不進 PWA／私人 query 持久快取；回應 private/no-store。
XLSX library 選型、年度查詢與缺漏投影的介面在工程 Contract 中固定。

完成條件包括：

- 上月、整年、閏年、跨日／時區、更正日期、歸檔與未指定場地結果正確。
- 收入／支出／負調整／多幣別、隱藏與參考列及缺費用情形都與權威帳本一致。
- 用合成資料示範收入 12,000、支出 3,000、支出沖減 -200，差額為 9,200；參考列不影響結果。
- Excel 和 Google Sheets 實際開啟 XLSX／CSV；中文、日期、金額、換行與注入字串符合規格。
- 兩個 Coach 隔離，Free／Pro 拒絕產檔，Prime 可用，產檔時降級／登出有明確行為。
- 桌機、390×844、安裝 PWA 的下載與另存流程分別驗證，不互相替代。
- 原有訓練／成長匯出退場與舊 API 相容處理在兩份新功能上線前定案；不能只藏 UI 卻宣稱撤除完成。
