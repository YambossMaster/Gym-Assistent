## 目標與範圍

`/students/venues` 的場地詳情以 **場地課程紀錄** 作為主要歷史入口，列出該場地
所有已完成的 Course Session。原 **過往支出類型** 成為此入口內的次要設定歷史，
保留每次支出類型、費率與金額的生效時間及變更內容。這個入口不建立第二份課堂：
每列對應一筆 Course Session，並連回其課堂頁。

列表至少顯示上課日期、起訖時間、學生姓名、場地支出或扣堂狀態與課堂連結。
點開課堂的場地紀錄可查看實際套用的規則、計算明細及人工調整。
資料量大時按課堂結束時間倒序分頁；空清單要說明該場地尚無已完成課堂。
已排未完成及已取消課堂不產生實際支出或扣堂；排課時可另顯示預估資訊。

## 生效時間與逐堂計算

場地支出規則由日期加時間構成一個 Workspace 時區中的生效時刻，儲存時要保留
可比較的絕對時間和原時區語意。對同一場地，依 Course Session 的**結束時間**
選取該時刻已生效的最新一版規則。採 `課堂結束時間 >= 生效時間`，同一時刻
最多一版規則，規則未生效前沿用先前版本；沒有先前版本時視為不記錄場地支出。
課堂結束時間是 Course Session 儲存的 `endsAt`，不以教練按下「完成」的時間
取代。跨午夜的課堂按結束時刻選規則及月份。購課時收整包抽成也使用購課的
日期與**時間**；輸入介面在 Workspace 時區顯示兩者，儲存絕對時刻，預設目前
日期時間，編輯時忠實顯示原值。同日中途變更規則不能只靠購課日期推定先後。
修改課堂時間、場地或規則前，預覽受影響的課堂、預購批次與月份，並以版本檢查
避免覆蓋並行修改。已完成課堂的人工設定不可被一般規則變更默默覆寫。

| 規則                 | 場地課程紀錄中的結果                                |
| -------------------- | --------------------------------------------------- |
| 不記錄場地支出       | 仍列出課堂，標示不記錄；不產生場地費。              |
| 免費場地             | 仍列出課堂，標示免費及已知 0 元。                   |
| 固定抽成             | 顯示適用比例及抽成已記錄的來源；詳見下段。          |
| 場地供客／自帶客抽成 | 顯示該堂客源分類、適用比例及抽成來源；詳見下段。    |
| 每堂租金             | 顯示該堂租金與幣別。                                |
| 預購場地堂數         | 顯示是否扣 1 堂、所屬預購批次、批次及場地剩餘堂數。 |

**指定場地學生購課的抽成仍於購課月份按整包金額記錄一次**。抽成比例不變的
課堂顯示比例、對應學生購課及「抽成已於購課時記錄」，不顯示虛構的逐堂實扣
金額，也不在完課月份重複加入抽成支出。若課堂結束時適用的抽成比例已變，
完課時只按該堂可歸屬的購課價格，計入新比例與**購課時已預計比例的差額**。
場地課程紀錄須顯示原比例、新比例、購課來源及差額；若新比例較低，差額為
沖減場地支出，不能當成新的收入。再次變更比例時，每堂仍相對該購課原比例
計差額，不重複補算前一次差額。取消不產生差額；重開已完成課堂撤回該堂差額。
無固定場地購課仍須等選定場地並完課後，
依該堂可歸屬的購課單價計算抽成，場地課程紀錄顯示比例、計算基礎、幣別及
該堂支出金額。沒有可歸屬價格時標示待補資料，不顯示虛構的 0 元。
若場地規則後來改為每堂租金或預購堂數，後續課堂依新規則計算；未上堂數
先前已計入的購課抽成**保留在原購課月份**，不自動退款。新租金或扣堂
從規則生效後結束的課堂另行計算。不同幣別分開計算。

## 預購批次、扣堂與人工指定

場地預購紀錄分開保存**購買日期／支出月份**及**開始扣堂的日期時間**。
購買金額只在購買月份列一次支出，課堂扣堂不再產生相同金額的第二次支出。
一堂已完成課程最多扣一批預購的 1 堂。系統只為結束時間不早於該批次起扣時刻、
當時套用預購規則且尚未豁免的課堂自動配對可用批次。**後買的批次也可補扣
較早未扣課**，條件是該課的結束時間不早於新批次所填的起扣時刻；不符合
起扣時刻的舊課不自動補扣。同時有多堂待補扣時，按結束時間及穩定 ID
從早到晚處理；同時有多批可用時，依起扣時間、購買日期及穩定 ID 排序。
既有有效的扣堂指向及明確不扣設定不因新增批次被改寫。批次已滿不得再配對，不能把同一堂課
重複扣在兩批。教練可在場地課程紀錄中改為不扣、恢復自動扣堂，或改指向同場地
尚有容量的批次。教練明確操作時可將較早的未扣課追溯指向該批次，儲存前顯示
該批次原起扣時刻、變動的批次餘額與受影響的課堂；自動配對仍遵守起扣時刻。

介面必須區分：**不扣堂**（規則未開始、明確豁免或非預購規則）、
**未紀錄扣堂**（應扣但沒有符合條件且有餘額的批次）、**已扣堂**（指向一筆批次）。
未紀錄扣堂不能在批次明細中冒充已扣堂；場地層級分開顯示可用堂數、
待處理堂數及扣除待處理後的淨餘額，不能讓沒有批次指向的欠堂看似已分配。
每筆已扣堂摘要顯示該批次依目前有效分配、按課堂結束時間與穩定 ID 排序後，
扣除當下剩餘 `X / Y` 堂。較早課堂後補扣時，重算該批次更晚課堂的 `X`；
較早已扣堂的值不變。批次詳情可另顯示目前剩餘堂數，須清楚區分兩種時間意義。
預購批次編輯／刪除、完課重開、改課堂場地或時間時，都要重新檢查配對；
預購新增與編輯直接儲存，更新後的扣堂與收支結果可從場地課程紀錄及收支明細查看。
改課堂場地或時間及逐堂人工指定仍顯示影響預覽。手動指定若失效，要提示衝突並保留課堂紀錄，不可悄悄改指其他批次。
場地餘額不足仍不阻止排課或完課；低餘額提醒與待處理堂數需分開呈現。

## 場地紀錄與收支明細的關係

場地課程紀錄是逐堂場地費的計算來源；**收支明細**是按月份呈現的結果及
使用者對結果的獨立修正。修改課堂的場地紀錄，會重新計算沒有手動修正的對應
明細與月總額。使用者在收支明細修改金額，不反向修改課堂、規則或預購扣堂。
兩處應有同一來源連結，但不能靠複製一份可互相覆寫的課堂資料維持同步。
Product Owner 已確認：手動修正後若來源改變，保留手動金額，標示
「來源已變動」，提供重新計算值供檢視與明確重設；不得默默覆寫。預購整批
支出、學生購課收入及底薪
仍各有原本的來源，不應偽裝為逐堂場地支出。

## 逐堂修改、持久資料與操作

場地課程紀錄由已完成的 Course Session 和其 Venue ID 投影，不複製 Session。
每列保留實際使用的規則版本、學生購課來源、客源分類、支出計算狀態，以及
預購扣堂批次 ID 或未扣原因。規則版本與購課原比例必須可追溯；不能只記
一個隨後會變的「目前比例」。每筆人工修改保留修改時間與版本，並由 API
驗證同一 Workspace 的場地、課堂、購課及預購批次。修改場地費只改該堂，
不改場地預設規則；修改場地規則則影響生效時刻之後符合條件的課堂，但不
默默清除已明確指定的逐堂設定。

逐堂編輯可設為自動計算、明確不扣／不計費，或輸入該堂的費率或金額。
指定場地購課若抽成已整包計入，逐堂費率編輯只調整該堂與購課原比例的
差額，不修改原購課月的整包支出。預購模式只有扣 1 堂／不扣及批次指向，
不提供小數堂或把同一堂扣到多筆預購。逐堂金額、客源或扣堂修改需先顯示
受影響的來源、月份、批次餘額與計算前後值，再以版本檢查提交。

新增及修訂的 HTTP 操作如下。所有路徑延續現有 `/v1`、驗證 Coach 身分與
Workspace，錯誤與衝突回傳目前授權範圍內的資料及版本；不開放任意資料表更新。

| 操作               | HTTP                                                  | 契約                                                                                                                          |
| ------------------ | ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 場地課程紀錄       | `GET /v1/venues/:venueId/course-records?cursor=…`     | 依結束時間、Session ID 倒序，每頁最多 30 筆；含課堂連結、規則、抽成來源／差額、扣堂批次、餘額與修改狀態。                     |
| 逐堂修改／重設     | `PATCH /v1/venues/:venueId/course-records/:sessionId` | Session 與場地紀錄版本；選擇自動、明確不扣、指定可用預購批次，或該堂費率／金額修正；回傳受影響月份和批次餘額。                |
| 場地規則預覽／儲存 | 既有 `/v1/venues/:venueId/fee-rules` 操作             | 改收 `effectiveAt` 絕對時刻及本地日期時間；依 Session 結束時刻預覽受影響課堂、月份與扣堂。                                    |
| 預購新增／更正     | 既有 `/v1/venues/:venueId/credit-purchases` 操作      | 保留 `purchasedOn` 作為支出日期，另收 `startsDeductingAt`；新增與編輯直接儲存並重新計算扣堂及收支，失敗時保留輸入並顯示錯誤。 |

逐堂修正的可選欄位依規則限制：預購可選自動、不扣或指定同場地有餘額批次；
租金與一般購課抽成可選自動、不計費或調整該堂金額／比例；已在指定場地
購課時記錄的抽成只可調整該堂**差額**，不可把整包原抽成重算成逐堂費。
收支明細的修改、新增、刪除、恢復及月總額改由
`M7.5-FINANCE-LEDGER-MANAGEMENT-CONTRACT.md` 定義。抽成差額的來源金額
可為正或負；一般來源收入與支出為非負數。
有價值的使用者輸入在衝突或網路失敗後留在編輯器中。

既有場地規則操作改收 `effectiveAt`，預購批次操作另收
`startsDeductingAt`，購課表單與 API 確認完整 `purchasedAt`。
收支明細每列提供穩定來源識別、原始計算值、實際顯示值、人工修正狀態與
來源變動狀態；手動修改／重設是獨立、版本化的 Finance 操作，不更新
來源 Session、Venue 規則或預購批次。來源版本改變後保留手動欄位，直到
教練明確修改或重設。批次剩餘、未紀錄堂數及月報由伺服器統一投影，
前端不能自行拼接正式計算。

初讀取、空清單、分頁載入、局部讀取失敗、背景更新、提交中、版本衝突、
批次容量衝突及來源已變動都要有可恢復狀態。衝突顯示目前伺服器資料，
保留未提交編輯；私人財務及教練備註不得進入公開課堂結果。

場地詳情將原 **過往支出類型** 主入口改名為 **場地課程紀錄**，點開先看
逐堂列表，列表內另有 **過往支出類型** 入口。單堂詳情依狀態顯示
**已於購課時記錄抽成**、**抽成差額**、**租金**、**不扣堂**、
**未紀錄扣堂**或**已扣堂 · 預購日期**，並提供 **查看課堂**、
**修改場地紀錄**。編輯後有明確的儲存與取消；批次選項顯示購買日期、
起扣時間及剩餘堂數，沒有餘額的批次不可選。收支明細的人工修正列標示
**已手動調整**；來源後續變動時再標示 **來源已變動**，提供
**查看重新計算金額**及 **重設為計算金額**。桌面及精確 390×844 都要能
完成列表、詳情、改扣堂、改費率、返回場地及收支明細來源跳轉；鍵盤順序、
對話框焦點、長清單捲動及文字溢出要驗收。
場地課程紀錄以關閉操作逐層返回：逐堂編輯、單堂詳情、紀錄列表、場地詳情；
單堂詳情不另放重複的「返回紀錄列表」按鈕。適用規則採可展開摘要，
購課來源資訊在所有單堂詳情中保持同一位置，沒有對應購課時明示原因。

## 驗收案例與資料處理

- 生效時間剛好等於課堂結束時刻，以及同日較早／較晚結束的課堂，選到正確規則。
- 先抽成、後租金、再預購；三段課堂各留有正確規則、金額或扣堂狀態。
- 指定場地購課先按 20% 記整包抽成，變更為 30% 後只為後續已完成課堂
  補記 10 個百分點的差額；降為 10% 時沖減場地支出，不能再記一次全額抽成。
- 同一天 11:00 購課、14:00 改抽成、16:00 再購課，兩筆購課用各自時刻的比例。
- 整包抽成後改為租金或預購，保留原月抽成；新規則只作用於生效後結束的課堂。
- 購買日與起扣日不同；起扣前的已完成課堂不自動扣新批次。
- 後買批次若把起扣時刻設在一堂舊課結束以前，該舊課可自動補扣；設在
  舊課結束以後則不補扣，但可由教練明確指定到仍有餘額的批次。
- 多筆預購用盡、未紀錄扣堂、手動豁免、改指另一有餘額批次、批次刪除、
  完課重開、重複提交及版本衝突均不重複扣堂。
- 場地課程紀錄修改後，相應收支月份更新；收支明細的人工修改不回寫原始課堂。
- 來源課堂改動後，手動修改的收支明細金額仍保留並標記來源已變動；重設後
  才恢復伺服器的最新計算值。
