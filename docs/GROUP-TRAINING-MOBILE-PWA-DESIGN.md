## 教練在手機上的操作

1. 沿用現有手機課程頁的頂部「訓練紀錄／教練筆記」分頁、課程摘要和底部「完成上課」。
2. 訓練紀錄上方的手機控制區第一列左側顯示「今日出席」，右側是精簡的「按時序／按學生」切換；第二列將學生頭像與姓名靠左收攏。點學生切換出缺席；缺席者變暗，其組數和新增入口暫時不顯示，原有輸入仍保留在同一份草稿中。
3. 視圖切換使用小型淺灰膠囊底框，選中的項目為白底深色文字與輕微陰影；避免與上方導覽分頁共用底線語意。兩個選項各維持單行與 30px 點擊高度。兩種畫面讀寫同一份動作與組數資料，不複製紀錄。
4. 動作仍是主要卡片。「按時序」依實際新增順序列出各學生組數，卡片底部有每位出席學生的專屬新增按鈕，按鈕以對應學生的淡色作背景，保留既有文字與邊框。「按學生」則在每人的標題列放「新增一組」，方便連續對照同一學生。
5. 每組沿用正式單人紀錄的單行格線：「按時序」以彩色圓標內的數字表示該學生的組號，學生身分由上方名單對應的顏色辨識；「按學生」沿用組號。兩種模式的重量、次數、RPE、結果與刪除欄位使用相同起點和寬度；RPE 欄位底色與重量、次數一致。「按時序」的第一欄表頭在手機顯示「組」，桌面仍顯示「學生」。手機結果按鈕沿用原版圖示，保留可讀的無障礙名稱。第三位學生改用莓紅色，與藍、橘明確區分。
6. 手機動作標題不顯示「幾人有紀錄」。若沒有可記錄的出席學生，省略空表頭，在卡片內容區顯示置中的簡短狀態訊息。
7. 手機的每人「新增一組」控制沿用原版按鈕的 36px 高、9px 字級與 16px 加號；多人紀錄列只保留外層的一條分隔線。

## 沿用與邊界

- 仍使用桌面範本的 `GroupTrainingModesPrototype` 草稿、既有 `SetCard` 和 `MeasurementInputs`；手機只改呈現位置與密度。
- 顯示模式是檢視偏好，不改組數歸屬或時間順序。預覽頁可直接切換、輸入和新增，便於評估操作摩擦。
- 此頁是設計預覽。群組購課、排課、正式出缺席及個人歷史歸屬，仍須由未來的正式 Contract 與 API 實作。

- 2026-10-19 在本機 390px 預覽：兩種模式可切換；「按學生」新增科比牢二的一組由 2 組變 3 組，切回「按時序」後總數同步增加；把學生 B 設為缺席後，其組數暫不顯示。依 Product Owner 回饋恢復每組單行，並修正頭像色與空狀態。390px 與 320px 的兩模式重量、RPE、結果與刪除控制有相同起點和寬度，沒有橫向捲動。最新控制列在兩種寬度下維持單行膠囊切換器，學生入口靠左且各有 36px 高度；RPE 與重量欄位的計算後底色同為 `rgb(247, 247, 243)`。兩模式的每人「新增一組」在對應顏色下具有相同底色、邊框、文字色與 36px 高度。
