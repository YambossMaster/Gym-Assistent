## Evidence rule

- **Passed:** the named scenario ran in this Stage 2 pass with an observed result.
- **Partial:** a narrower browser or API path ran, while another required interaction remains.
- **Pending:** no current Stage 2 evidence for that scenario.
- **Product decision:** the expected route hierarchy or acceptance boundary requires Product Owner
  review before implementation or sign-off.

The current app is a local Web/PWA development build. `mobile-preview.html` and browser viewport
overrides exercise its responsive UI. They do not prove installed PWA safe areas, touch gestures,
mobile soft keyboards, or production behaviour. M8 owns staging and production setup.
On 2026-10-01, the Product Owner explicitly deferred physical Android/iOS installed-PWA testing
until the app can be reached from a phone. Record this as a known evidence gap, not a pass; run the
installed-device journeys on M8-B isolated staging before the production Alpha gate.
The page-edge scrollbar seen in desktop Chrome's narrow viewport is a desktop-browser simulation
artifact, not a mobile UI element or an expected phone/PWA scrollbar. Only scrollbars deliberately
owned by the app's internal panels are part of the mobile visual review.
